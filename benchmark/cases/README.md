# UrbanTrace Benchmark Cases

This directory contains per-case evidence-backed benchmark files for the UrbanTrace agent evaluation.

Format for each case file (`<id>-<slug>.md`):

- Task description (from seeds)
- Search queries used (for reproducibility)
- Selected supporting references (title, authors, year, venue, url, short rationale, confidence)
- Selected dataset links (if any) with access notes
- Notes / follow-ups

Files here are generated and maintained by the UrbanTrace assistant (Adam). If you want a different format (JSON-only, Chinese language, etc.), edit `../config.json` or tell Adam to change the template.
